*Draft: 1.0.2 is not released yet. More fixes may join it before it is.*

Your save carries over as it is: install this over 1.0.1.

## Changed

- **A dragon's Training page** (its level, stats and moves, on the bottom screen) has its words a size larger,
  with the rows respaced so nothing touches.

## Fixed

- **Swapping a move:** tapping one of a dragon's four moves opened the list of moves it knows and, with the
  same tap, took whichever move happened to lie under the stylus, so the list was gone before you saw it. The
  list now stays until you pick from it or cancel.
