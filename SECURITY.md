# Security

*Emberclutch* is an offline 3DS game: it has no network features and reads and writes only its own files on the SD
card (its save, its photos and screenshots, a log if it freezes). Security problems are still possible, for example a save
file crafted to crash the game or to run code through it.

## Supported versions
Only the latest release gets fixes.

## Reporting a problem
Please don't open a public issue for a security problem. Use GitHub's private vulnerability reporting:
the repository's **Security** tab, then **Report a vulnerability**. Say what you found, how to reproduce
it (a save file or steps), and what it lets someone do.

You'll get an answer within a week or two. Once it's fixed, the release notes credit you if you'd like.
