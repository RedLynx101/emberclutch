The first nine dragons

All eight base breeds and the first crossbreed, built for the storybook look: three common, three harder to find, two rare, and the Blazeplume. Every picture is the game's own model, moved by its own animations, in the colours the 3DS shows. The last row of each is the game itself running in the den.

Pick Keep it, Small tweaks or Rethink for each dragon and add notes. Tap any picture to see it full size. Everything saves as you go, and Claude reads it back. Connecting…

At a glance

Rarer kinds start with better stats: common ones total 28, harder to find 31, rare 34, and the Blazeplume sits a little above its better parent. Size is grown size next to a Pouncer; the breeds span about ±50%.

A few questions before DR3

Each kind was built by its own Claude subagent (Opus 5.5) on the shared dragon kit, then merged, checked (bones, triangles, every clip) and run in the Azahar emulator with no memory faults. The concept images were reference only; nothing from them is in the game.
